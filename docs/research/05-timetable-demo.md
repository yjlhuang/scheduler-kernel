# 05 — timetable-demo

Evidence: public repository.

Observed shape: browser-local timetable import and query/lookup flows, with data kept in local storage. Its center of gravity is consuming and searching a timetable rather than generating an optimized master schedule.

Useful concept: schedule views are derived consumers, and local-first handling can reduce privacy risk.

Not adopted: login/query UI and presentation layer. Phase 0 represents these only as version-pinned derived artifacts.
