# 06 — class-swap-radar

Evidence: public repository and its handoff document.

Observed shape: decision support for a specific teacher-initiated swap, including candidate filtering, human-readable reasons a candidate fails, reversible trial swaps, and a swap log.

Useful concept adopted: repair is a local operation with a precise request, explicit changed set, and preservation metric—not a silent global regeneration.

Not adopted: the browser UI, local-storage format, or complete multi-step swap workflow. Phase 0 proves a one-target repair with all other lessons locked.
